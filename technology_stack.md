# Technology Stack - OHMies

## Frontend
*   **React:** Core library for building the user interface, managing state for the three tabs, and componentizing the views.
*   **Tailwind CSS:** Utility-first CSS framework for rapid, attractive UI styling.
*   **HTML/CSS:** Foundational web technologies, specifically used to port over designs from the provided reference files.

## Backend
*   **FastAPI:** High-performance web framework for building APIs with Python 3.7+. Used for serving data and handling login requests.
*   **Python:** The core backend programming language.

## Data & Storage
*   **Supabase:** Open-source Firebase alternative serving as the PostgreSQL database backend. Holds the pre-existing datasets.

## Machine Learning & Analytics
*   **scikit-learn (sklearn):** Python library used to process statistical data, find insights, and calculate averages or predictive models for the "Average Daily Draw" and "Peak Window Intensity".

## Version Control & Environment
*   **Git:** Version control.
*   **.gitignore / .env:** Used to securely store the mock Name and Password away from the public source code.
